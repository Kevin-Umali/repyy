Every repository leaves a trace.

repyy follows the traces that matter before trust becomes execution.

01

Install paths, exposed.

Lifecycle scripts, build hooks, custom registries, unsafe binaries, and download-to-execute chains.

02

03

Entropy, encoded payloads, eval chains, invisible characters, and string shufflers.

Context, not panic.

repyy reports the limits that reduced coverage instead of hiding them behind a clean-looking result.

10 minDefault timeout
100,000Default file limit
50 MiBDefault per file

These are documented defaults, not detection guarantees. Change them when the repository calls for a wider pass.

Questions before your first scan.

Does “No findings” mean the repository is safe?

No. It means the completed scan matched no enabled rule. Static analysis can miss malicious behavior and can report harmless code.

Does repyy execute target code?

No. It reads target files as data. It does not install packages, build the project, run tests, or import source.

Can I scan private repositories?

Yes. HTTPS clones can use supported provider tokens. SSH remotes use your existing SSH agent.

Can a repository weaken its own scan?

No. Repository-owned .repyy.yaml files are ignored. Pass a configuration file you trust with the --config flag.
